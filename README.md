# Work Timer для Visual Studio Code

**Work Timer** — это легкое и эффективное расширение для Visual Studio Code, созданное для управления временем по методу Pomodoro. Оно помогает разработчикам сохранять фокус, контролировать циклы работы и отдыха прямо из редактора, отслеживать статистику и избегать выгорания.

---

## Основные возможности

* **Интеграция со статус-баром:** Отображение текущего статуса таймера и интерактивного меню действий в правом нижнем углу VS Code.
* **Гибкая настройка интервалов:** Легкое изменение длительности рабочих сессий и перерывов через настройки редактора или через диалоговые окна.
* **Сохранение статистики:** Автоматический учет общего времени работы и отдыха с сохранением данных между перезапусками редактора (через `globalState`).
* **Быстрое меню управления:** Выпадающий список команд (Quick Pick), открываемый одним кликом по статус-бару.
* **Уведомления с выбором действий:** Наглядные сообщения по окончании таймера с возможностью начать перерыв, отложить работу на 5 минут или пропустить отдых.

---

## Быстрый старт

1. **Активация:** После запуска расширения первый рабочий цикл начинается автоматически.
2. **Меню в статус-баре:** Кликните по иконке таймера в статус-баре, чтобы открыть меню быстрых действий:
   * **Запустить / Перезапустить таймер:** Начать новый рабочий интервал.
   * **Остановить таймер:** Поставить таймер на паузу с сохранением текущего прогресса.
   * **Сделать перерыв сейчас:** Принудительно перейти в режим отдыха.
   * **Показать статистику:** Посмотреть накопленное время работы и отдыха.
   * **Настроить время:** Изменить длительность сессий.
   * **Сбросить статистику:** Обнулить сохраненные показатели.

## Параметры конфигурации

Вы можете настроить длительность интервалов через стандартные настройки VS Code (`Ctrl + ,` / `Cmd + ,`), найдя раздел **Work Timer**:

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `workTimer.workDuration` | `number` | `40` | Длительность рабочего интервала в минутах. |
| `workTimer.breakDuration` | `number` | `10` | Длительность перерыва в минутах. |

---

## Команды Палитры (Command Palette)

Все функции доступны через Палитру команд (`Ctrl + Shift + P` / `Cmd + Shift + P`):

* `Work Timer: Открыть меню` — Вызов меню действий статус-бара.
* `Work Timer: Запустить таймер` — Старт или перезапуск рабочего цикла.
* `Work Timer: Остановить таймер` — Остановка таймера и фиксация времени.
* `Work Timer: Показать статистику` — Вывод текущей статистики.
* `Work Timer: Настроить время (работа/перерыв)` — Диалог изменения длительности.

## Сборка и разработка

Проект написан на **TypeScript** и собирается с помощью высокопроизводительного сборщика **`esbuild`**.

### Требования
* Node.js (версия 18+)
* Visual Studio Code (`v1.80.0` или новее)

### Установка и компиляция

```bash
# Установка зависимостей
npm install

# Однократная компиляция проекта
npm run compile

# Режим автосборки при изменении файлов (watch mode)
npm run watch
```

### Отладка

1. Откройте папку проекта в VS Code.
2. Нажмите **`F5`** для запуска нового окна отладки (**Extension Development Host**).
3. Тестируйте работу статус-бара и команд в реальном времени.
